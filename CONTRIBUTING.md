# Contribuer à Cliplex

Merci de vouloir améliorer Cliplex.

## Comment proposer un changement

1. Ouvre d'abord une issue pour décrire le problème ou l'idée, surtout pour un changement important.
2. Crée une branche depuis `main` et fais tes modifications.
3. Vérifie que tout passe : `npm run typecheck` et `npm run build`.
4. Ouvre une pull request en expliquant ce qui change et comment le tester.

Chaque pull request est relue, testée et validée par le mainteneur avant d'entrer dans la version officielle.

## Règles de style

- Interface et textes en français clair, en tutoiement.
- Pas d'emoji, pas de tiret long, pas d'icônes « magiques » (étoiles, éclairs, baguette).
- Design sobre : Inter, tailles compactes, violet réservé aux accents, pas de dégradé dans les textes.
- Toute installation ou commande lancée sur la machine de l'utilisateur doit être affichée et expliquée.
- Les données restent locales. Aucun envoi vers un service tiers sans action explicite de l'utilisateur.
